# Contribution and evidence boundaries

## Yushan Wu

My contribution to the underlying team project was evaluation: comparing versions, applying the rubric, checking source support, investigating failure cases and preparing findings for iteration. AI tools assisted parts of the analysis and report preparation.

The learning assistant's overall development, retrieval implementation, interface and deployment were team work. This repository does not attribute that complete implementation to me. Creating this case-study repository also does not retroactively establish code contributions to the original team's GitHub history.

## Evidence used for this portfolio

- Retained A/B/C run handoff: 20 cases per variant, 60 outputs; A-1.0, B-1.0 and C-1.3.
- Retained independent-review workbook export: aggregate and module results transcribed in the two CSV files.
- Retained C-1.2 case-review notes: paraphrased in FAILURE_CASES.md and kept separate from the later comparison.

This portfolio was assembled in November 2026 from those historical records. No new application run or API evaluation was performed to create it. Raw course materials, full application code, credentials and private working files are not part of the publication.
